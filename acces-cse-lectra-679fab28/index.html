Accès CSE Lectra

Pour l'informaticien de l'intranet du CSE Lectra : comment créer le lien qui donne aux salariés le tarif CSE sur la boutique Maison des Pierres (Cognac Léopold Croizet et Cognac Esprit Organic).

Principe

Le lien est fabriqué par le serveur de l'intranet au moment où un salarié connecté clique. Il est signé, valable 10 minutes et utilisable une seule fois. Recopié ou transféré, il ne donne pas la remise.

Vos paramètres

Identifiant
cse-lectra
Clé secrète
76f364eabb9a8ebf03f3c7d7b8e3b8f4757900062ad39ef168473ff7c73b0522
Adresse
https://boutique.mdpierre.com/commander/

La clé reste sur le serveur de l'intranet : jamais dans une page, un navigateur ou un lien.

À chaque clic

  1. ts : l'heure actuelle en secondes (timestamp Unix, 2 minutes de tolérance).
  2. nonce : 32 caractères aléatoires (0-9 a-f).
  3. sig : HMAC-SHA256 en hexadécimal du texte cse-lectra.ts.nonce, avec la clé secrète telle quelle.
  4. Rediriger le salarié (HTTP 302) vers :
    https://boutique.mdpierre.com/commander/?mdp_cse=cse-lectra&mdp_ts=ts&mdp_nonce=nonce&mdp_sig=sig

Exemple PHP

<?php
// Page de l'intranet réservée aux salariés connectés, ex. /cognac
$id     = 'cse-lectra';
$secret = getenv('MDP_CSE_SECRET');   // la clé secrète, stockée côté serveur
$ts     = (string) time();
$nonce  = bin2hex(random_bytes(16));
$sig    = hash_hmac('sha256', "$id.$ts.$nonce", $secret);
header('Location: https://boutique.mdpierre.com/commander/?' . http_build_query([
    'mdp_cse' => $id, 'mdp_ts' => $ts, 'mdp_nonce' => $nonce, 'mdp_sig' => $sig,
]), true, 302);
exit;

Exemple Node.js

const crypto = require('crypto');
app.get('/cognac', requireLogin, (req, res) => {
  const id = 'cse-lectra';
  const ts = Math.floor(Date.now() / 1000).toString();
  const nonce = crypto.randomBytes(16).toString('hex');
  const sig = crypto.createHmac('sha256', process.env.MDP_CSE_SECRET)
    .update(`${id}.${ts}.${nonce}`).digest('hex');
  res.redirect(302, `https://boutique.mdpierre.com/commander/?mdp_cse=${id}&mdp_ts=${ts}&mdp_nonce=${nonce}&mdp_sig=${sig}`);
});
