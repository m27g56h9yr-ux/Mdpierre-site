Principe

Le lien est fabriqué par le serveur de l'intranet au moment où un salarié connecté clique. Il est signé, valable 10 minutes et utilisable une seule fois. Recopié ou transféré, il ne donne pas le tarif CSE. Le salarié arrive sur le site Cognac Esprit Organic ; ses achats sur la boutique Maison des Pierres sont alors au tarif CSE pendant 3 heures.

La clé reste sur le serveur de l'intranet : jamais dans une page, un navigateur ou un lien.

À chaque clic

  1. ts : l'heure actuelle en secondes (timestamp Unix, 2 minutes de tolérance).
  2. nonce : 32 caractères aléatoires (0-9 a-f).
  3. sig : HMAC-SHA256 en hexadécimal du texte ….ts.nonce, avec la clé secrète telle quelle.
  4. Rediriger le salarié (HTTP 302) vers :
    https://cognac-esprit-organic.com/acces-cse/?mdp_cse=…&mdp_ts=ts&mdp_nonce=nonce&mdp_sig=sig

Exemple PHP

<?php
// Page de l'intranet réservée aux salariés connectés, ex. /cognac
$id     = '…';
$secret = getenv('MDP_CSE_SECRET');   // la clé secrète, stockée côté serveur
$ts     = (string) time();
$nonce  = bin2hex(random_bytes(16));
$sig    = hash_hmac('sha256', "$id.$ts.$nonce", $secret);
header('Location: https://cognac-esprit-organic.com/acces-cse/?' . http_build_query([
    'mdp_cse' => $id, 'mdp_ts' => $ts, 'mdp_nonce' => $nonce, 'mdp_sig' => $sig,
]), true, 302);
exit;

Exemple Node.js

const crypto = require('crypto');
app.get('/cognac', requireLogin, (req, res) => {
  const id = '…';
  const ts = Math.floor(Date.now() / 1000).toString();
  const nonce = crypto.randomBytes(16).toString('hex');
  const sig = crypto.createHmac('sha256', process.env.MDP_CSE_SECRET)
    .update(`${id}.${ts}.${nonce}`).digest('hex');
  res.redirect(302, `https://cognac-esprit-organic.com/acces-cse/?mdp_cse=${id}&mdp_ts=${ts}&mdp_nonce=${nonce}&mdp_sig=${sig}`);
});
